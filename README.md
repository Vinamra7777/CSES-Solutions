## 📂 Repository Structure
The solutions are strictly organized by topic to mirror the CSES structure:
* `/01-Introductory-Problems` - Basic simulation, recursion, and bitwise logic.
* `/02-Sorting-and-Searching` - Binary search, two pointers, greedy strategies, and scheduling.
* `/03-Dynamic-Programming` - Classic DP states, knapsack variations, and grid optimizations.
* `/04-Graph-Algorithms` - DFS/BFS traversal, Shortest Paths (Dijkstra/Bellman-Ford), and MST.
